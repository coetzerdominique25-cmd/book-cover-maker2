Back to school means a pile of new books to cover and label. Make the whole set in one go: choose the subjects, set copies for subjects with more than one book, and print one PDF.

Designing and previewing is free. Downloading the print-ready PDF costs R50 for the first set (one learner), and R25 each for the 2nd and 3rd set in the same pack. Each pack lasts 4 months.

How it works

  1. Type your child's name and grade (and school, if you like).
  2. Pick the subjects and one of 12 themes. Preview every cover for free.
  3. Unlock and download one PDF, then print on A4 at home.
